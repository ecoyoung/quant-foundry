# 16 周阅读路径

| 周次 | 主题 | 必读 | 实践输出 |
|---|---|---|---|
| 1–2 | Python 与市场数据 | NumPy Quickstart；pandas 10 minutes；SEC Trading Basics | 清洗一份 OHLCV 数据并计算收益率 |
| 3–5 | 概率与组合风险 | MIT 18.05 选读；MIT 15.450 概率复习 | Bootstrap 收益分布与风险仪表盘 |
| 6–8 | 时间序列与因子 | MIT 18.642 时间序列讲义；pandas Windowing | 复现动量或均值回复因子 |
| 9–11 | 回测与成本 | LEAN Algorithm Engine；Trading and Orders | 带手续费和滑点的事件回测器 |
| 12–14 | 模型与验证 | scikit-learn TimeSeriesSplit；PBO 论文摘要与结论 | Walk-forward 验证报告 |
| 15–16 | 模拟盘与报告 | LEAN Research-to-Production 文档 | 策略说明书、风险清单与答辩 |

每次研究至少回答四个问题：数据何时可得？假设为何存在？成本如何估计？策略在什么条件下失效？
