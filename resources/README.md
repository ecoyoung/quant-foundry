# 砺金量化学习资料库

这是一份面向零基础学习者的“原始资料索引”，与课程内容分开保存。资料按权威性、可复现性和课程相关性筛选，优先顺序是：大学公开课与监管机构、论文原文、官方技术文档、成熟开源项目。

更新时间：2026-08-11

## 目录

- `downloads/`：允许公开下载并适合离线阅读的资料。
- `catalog.md`：完整资料目录、阅读建议与课程映射。
- `github-projects.md`：开源项目清单及使用边界。
- `reading-path.md`：按 16 周课程安排的阅读顺序。
- `LICENSE_NOTES.md`：版权、许可和使用说明。
- `../courseware/`：53 节课的完整代码、确定性数据、依赖和预期输出。

## 使用建议

不要从头到尾通读所有资料。先跟随 `reading-path.md` 完成指定章节，再把官方文档当作字典使用。论文首先阅读摘要、结论和图表，等学完对应数学工具后再读推导。

> 本资料库用于教育与研究，不构成投资建议。课程中的收益数字均为教学示例。

## 可复现实践

课程代码与数据位于项目根目录的 `courseware/`。运行：

```bash
python3 courseware/generate_assets.py --data-only
python3 courseware/verify_all.py
```

网页中每节课均提供本课入口、共享完整实现、本课数据、预期输出和完整实践包下载。
