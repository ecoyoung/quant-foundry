# 量研课学员使用手册

## 开始学习

1. 打开课程首页，系统自动定位第一节未完成课程。
2. 每课依次完成“理解概念、完成实践、检查理解”。
3. 实践必须同时通过标准案例和分步练习，才会解锁检查题。
4. 阶段项目达到 80 分且代码实践通过后完成。

## 代码实验

- `⌘/Ctrl + Enter`：运行当前代码。
- `Tab` / `Shift + Tab`：缩进或取消缩进。
- `⌘/Ctrl + F`：打开搜索与替换。
- “差异”：比较当前代码与课程标准入口。
- “快照”：保存命名版本，之后可从底部菜单恢复。
- 运行超过 45 秒会自动终止，也可随时点击“取消”。

## 离线使用

在“离线与安装”点击“下载离线课程”。进度达到 100% 后，53 节课程、代码、CSV 和固定输出可离线访问。浏览器 Python 核心需要至少联网成功运行一次。

## 保护学习成果

定期在“可靠性中心”导出完整 JSON 备份。恢复会导入课程进度、代码草稿、运行历史、实验和阶段项目。研究成果还可从“研究工作台”导出 Markdown 或 HTML。

> 本课程仅供教育研究，不构成投资建议。
