# 故障排查

## Python 一直加载

确认首次运行时网络可访问 Pyodide CDN；等待不超过 45 秒。超时后点击重新运行会创建干净 Worker。

## 输出与固定快照不同

先恢复标准代码，确认数据文件未手工修改，再查看“首个差异”。常见原因包括未来数据、错误 `ddof`、价格填零、未排序时间索引和成本方向错误。

## 离线页面不可用

联网打开最新页面，在“离线与安装”重新下载课程包。开发环境更换端口或来源后需要重新缓存。

## 进度或草稿异常

先导出完整备份。可靠性中心会报告无法解析的记录数量。不要直接清空网站数据，除非已验证备份可以恢复。

## Service Worker 未更新

点击“应用新版本”；仍无效时清理离线包并刷新。维护者应确认 `sw.js` 中的版本字符串已更新。
